# Kamlesh Patel — Developer Blog & Portfolio

A responsive [Nuxt 4](https://nuxt.com) static blog and developer portfolio deployed on [GitHub Pages](https://kamlesh1808.github.io/kamlesh1808/).

## Features

- **Markdown-powered blog posts** with front matter metadata, tags, and reading time
- **About / Resume page** with experience, education, and skills
- **Topic-based browsing** — filter posts by tags
- **Client-side search** across titles, excerpts, and tags
- **Dark / Light theme toggle** with persistent preference
- **Private tools section** — write tool and draft posts behind a passcode gate
- **Google Translate integration** for multi-language support

## Tech Stack

- **Nuxt 4** with Vue 3 and TypeScript (strict mode)
- **Bootstrap 5** for layout and components
- **MarkdownIt** for server-side markdown rendering
- **Custom TOML parser** (zero dependencies) for About page data
- **GitHub Actions** CI/CD pipeline with static generation

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000/kamlesh1808/` in your browser.
