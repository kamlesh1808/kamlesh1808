Coding AI tools have become an everyday part of my life as a Software Engineer.

In the past year, I have used Codium and Cody, IntelliJ plugins that let me write code from scratch, review code, improve existing code, write unit tests for new code, and convert unit tests from one framework to another, for example, JUnit to Kotlintest. The list of things I have used them for is very large.

These IDE plugins internally use OpenAI, Anthropic Claude, and other AI systems. I have used AI tools on the web and mobile as well. They have all been getting better with each new version. Recently, Claude version 3.7 was released, and I could see significant improvements.

I have tested DeepSeek, Gemini, Qwen, and Grok as well.

I have been using three benchmark questions, and the improvements over time are quite evident. I tested Qwen and Grok to generate images as well. In one test Qwen and Grok performed equally well. In another test, Qwen produced a good picture and Grok refused to draw it.

I have been embracing AI to write more complete code quickly and efficiently.

I have seen other applications of AI; producing creative short films is something I look forward to.
