Recently, my daughter asked me to review an exercise question from her Python programming assignment. In the conversation, the following software engineering principles were reaffirmed.

## Problem-solving

- Understand the problem first. If the question or task is not clear, ask for clarification.
- After you think you understand the problem, talk it through with the presenter and reaffirm your understanding. Take the hints provided by the presenter.
- Break the larger problem into smaller tasks and complete each smaller task with the expected input and output. Use debug and print statements if needed.
- Use the knowledge gained from previously completed simple tasks and apply it to the larger problem.

## Quality assurance testing

- Start with the most basic tests, also known as happy-day scenarios.
- Sometimes the devised test expectations are incorrect. Run through the workflow and its output on paper.
- A software engineer is also a QA tester. Their skills go hand in hand.

## Performance matters

- Develop a working solution first that solves the requested requirement.
- When ready, review the performance of the workflow or algorithm. First try to improve it through thought, then apply that idea in code.
- Retest to verify the functionality and measure the performance improvement.

Overall, software engineering is an iterative and creative process that takes time and persistence.
